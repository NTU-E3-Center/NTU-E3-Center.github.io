Evaluating a battery energy-storage project means pulling together a lot of
moving parts — a client's electricity-use data, candidate capacity
configurations, revenue and financial projections, and side-by-side scenario
comparisons. Yiho International Co., Ltd. already has well-developed practices and
financial logic for this. As case volume grows and parameters change often,
this industry-academia project (2026–2027), led by the E3 Center, helps turn
that established know-how into a purpose-built assessment tool — making the same
trusted expertise faster to apply and easier to scale.

The goal is a support tool that mirrors and streamlines Yiho's existing workflow
end to end: importing and organizing load data with basic time-of-day and monthly
analysis and visualization; comparing storage capacity configurations and benefit
scenarios; integrating the existing revenue and financial calculations for
parameter-by-parameter comparison; codifying the current practical decision rules
into consistent calculation and output logic; and generating standardized report
and presentation formats for both internal review and external proposals. A final
strand covers parameter updates, version management, and usage guidance so the
tool stays maintainable after handover.

The project is run collaboratively — through regular meetings and continuous
communication to confirm requirements, adjust features, and accept deliverables,
with each stage refined against real usage. In practical terms it brings the
E3 Center's energy-systems and techno-economic modeling to bear on a storage
developer's day-to-day evaluation work, improving both the efficiency and the
consistency of how storage projects are assessed and proposed.
