Welcome to the Editor Dashboard!

Your central hub for managing website content.

How to Use This Editor:

This dashboard allows you to easily update various sections of your website. Each tab corresponds to a different data type. When you make changes within a tab, the corresponding JSON file will be marked as "dirty" (modified) and will be included in the exported ZIP file.

General Controls:

  • Tabs: Navigate between different content sections (About, Members, Research, etc.) using the tabs at the top.
  • Expand/Collapse Sections: Click on the header of any content card (e.g., "Member 1", "Research Topic") to expand or collapse its details.
  • Input Fields: Directly edit text, URLs, and other data in the provided input fields. Changes are saved internally as you type.
  • Add/Remove Buttons: Use the "Add New..." buttons to add new sections or items within a section. Use "Remove" buttons to delete them.
  • Drag and Drop (Members & Research): Reorder members within a section or research topics within a section by dragging and dropping their cards.

Exporting Your Changes:

  • Export Individual JSON: Each content tab has an "Export [Section Name] JSON" button. Clicking this will download only the JSON file for that specific section, regardless of whether it was modified.
  • Export All Data as ZIP: The main "Export All Data as ZIP" button at the bottom of the page will generate a `structures.zip` file. This ZIP file will *only* include the JSON files for sections you have modified during your current session. This ensures you only export what's changed.

Specific Tab Functions:

  • About: Manage general information about the center, including article paths and sponsor logos.
  • Members: Organize team members into sections (Principal Investigator, Students, Alumni) and edit their details. Supports different forms for different member types and a filter for alumni.
  • Research: Define ongoing research topics, including tags (bigTags, smallTags) and associated fields (Energy, Economics, Environment).
  • Publications: List journal publications with citation details, links, and authors. You can also specify how many recent publications to show on the homepage.
  • News: Add news items with titles, links, and dates. Configure how many recent news items appear on the homepage.
  • Group Life: Showcase photos and events from group activities, with descriptions and dates. Includes options for a slider and year-based filtering.
  • Contact: Manage contact information and associated article paths.

Remember to export your changes regularly to save your work!
